# Чому саме ці теги


| Тег    | Що означає                  | Чому тут він, а не div                            |
| --------- | ------------------------------------ | -------------------------------------------------------------- |
| `nav`     | навігація                   | бо з ним можна створити нав панель |
| `storong` | робить текст жирним | бо він робить текст жирним               |
| `ul`      | створенн списку        |                                                                |
| `li`      | елемент списку          |                                                                |
| `footer`  | кінець сторінки        | показує де кінець                               |
