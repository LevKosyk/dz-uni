GrafQl - вона розвʼязуе задачу передачі данних через API. З нею нічого окрім запросу на сервер неможливо зробити, але вона спрощює цю роботу. 
Prisma Schema Language - використовуеться для створення таблицб у базі данних Prisma. Нічого крім цього з нею неможливо зробити. Вона робить простішими написання чи описання та створення таблицб у базах данних.
Redis Lua - використовуеться для написання скриптів для баз данних Redis. З нею не варто будувати сервер, тільки скрипти для данних. Вона робить простішими великі та складні запити.
