# Моя шпаргалка Git

| Команда | Що робить — своїми словами | Коли я її використаю |
|---|---|---|
| `git status` | побачити незакомічені зміни |коли хочемо побачити незакомічені зміни|
| `git clone` | клонувати репозиторій | коли хочемо клонувати репозиторій |
| `git diff` | побачити зміни зараз | коли хочемо побачити зміни зараз|
| `git add` | додати файл що б потім закомітити | коли хочемо додати файл що б потім закомітити|
| `git commit` | комітить зміни | коли хочемо комітить зміни |
| `git push` | пушить на гілку | коли хочемо пушить на гілку |
| `git log` | побачити історію коммітів | коли хочемо побачити історію коммітів|
